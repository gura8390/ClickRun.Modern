# 连点器 Modern

Rust 3.0.2，Windows 10/11 x64。以常驻内存为首要优化目标，使用 Windows 原生控件，不依赖 .NET、浏览器或 GPU 渲染引擎。界面沿用 ClickRun 的窄窗杂志风，默认约 460×640 逻辑像素，采用方正公文楷体、宣纸白背景、深墨文字、细线分隔和留白。

按本次确认的范围，连点固定为单击和固定间隔，已移除双击、三击和随机变化入口。旧配置格式继续兼容，相关字段按下文处理。

## 使用

打开 `连点器 Modern.exe`。启动时不连点。默认 F6 开始或停止；原版用户保留自己配置的热键。按下热键不必先打开主窗口。

1. 在主页面的按键分段按钮中选择左键、右键或中键。
2. 用间隔滑块或右侧 64 逻辑像素宽的数字框设置 1–10000 毫秒，两者联动。
3. 选择“无限”或“指定”；指定时在旁边的小数字框填写点击次数，再按“开始连点”或热键。
4. 按相同热键或“停止连点”停止。运行中锁定点击参数，应用设置仍可调整。

每次触发只执行一次鼠标单击，发生在当前鼠标位置；指定 7 次即执行 7 次单击。间隔不加入随机变化。1 毫秒是目标间隔，实际精度受 Windows 调度和目标应用影响。统计表示完整提交给系统的输入，不保证游戏或其他目标程序实际处理。连续 5 次发送失败会停止并显示中文错误。部分发送时补发释放，避免按键卡住。

主页面用小标签显示当前热键，旁边的“修改”打开热键设置。上方“方案”下拉框旁提供“存”和“删”：保存只包含点击参数，名称不能为空或重复；选择方案立即应用。旧方案中的模式和随机值也统一转为单击、无随机。

已点击、运行时长、点击速度和总点击次数直接以文字与数字显示，不使用大输入框。右上角“设置”进入设置页，“返回”回到主页面。窗口随 DPI 缩放；可用空间不足时提供纵向滚动。

## 设置与键盘

“设置”页提供登录启动、最小化到托盘、窗口置顶和启停音效，以及关于和配置文件夹入口。热键在主页面通过“修改”设置，可直接录入新组合，也可用按键下拉框及 Ctrl、Alt、Shift 开关选择。F12、Windows 键和单独修饰键不可用。新组合注册失败时保留原组合；Esc 取消对话框。对话框打开期间不会响应启停热键。

Tab / Shift+Tab 移动焦点，空格操作按钮或开关，方向键调整分段选择、下拉框和滑块。控件使用系统无障碍语义，提供中文名称、角色、当前值和固定数字 ID；统计和错误可作为文本读取。焦点移到屏外控件时自动滚入视野。主流程、滚动和数字框居中已通过本版本的对应回归测试。

托盘菜单提供主窗口、设置、开始或停止、退出。双击图标恢复主窗口。默认关闭或最小化时隐藏到托盘；关闭此选项后，关闭窗口退出。没有有效托盘图标时保留窗口并显示错误。“退出”始终停止连点、保存配置、移除图标并退出。使用 `--tray` 启动时隐藏到托盘，仍不开始连点。

## 配置与恢复

- 配置继续使用 `%AppData%\ClickRun\config.json`，承接旧热键、鼠标按键、间隔、次数、应用设置、方案名称、累计次数和未知扩展字段。
- `mode` 和 `randomDelay` 字段继续存在以兼容旧 JSON；加载、应用方案和开始连点时均归零，后续保存为单击、无随机。方案中的同名字段按相同规则处理。
- 上一有效版本为 `config.json.bak`。主文件损坏时留存 `config.json.corrupt-*` 并尝试恢复备份。
- 设置变更 500 毫秒后保存；运行累计每 5 秒保存检查点；停止、隐藏和退出时立即保存。
- 日志继续使用 `%LocalAppData%\ClickRun\logs\clickrun.log`，超过 1 MiB 后保留一份 `.1`。
- 登录启动读取真实注册状态，保留原 Run `ClickRun` 值和启动文件夹 `ClickRun.lnk` 两种渠道。用户切换时幂等维护两者，不覆盖指向无关程序的同名入口。

强制结束或断电可能丢失最近检查点以后的统计。配置写入失败会显示中文反馈并保留原文件。运行中请通过应用修改配置。

## 内存与 CPU 策略

空闲时通过消息与唤醒事件联合等待，没有工作线程或轮询计时器。运行时使用一个 64 KiB 栈工作线程、可取消的内核等待计时器、栈上输入包和固定 16 KiB 最近点击统计；不忙等，不逐次分配输入数组。显示窗口每 250 毫秒刷新，隐藏时降到每秒一次；空闲不刷新。字体从随包文件私有加载，不安装系统字体。

3.0.1 在首次显示窗口时创建控件、字体和无障碍名称服务；以 `--tray` 登录启动时，热键、托盘与连点引擎立即就绪。登录启动状态在进入设置页时读取真实系统状态，已确认启用的注册项无需再读取快捷方式；读取快捷方式的字符缓冲峰值减少 128 KiB。UIA 库在首次需要时透明加载，所有无障碍动作保留。

测试分别记录托盘启动、主窗可见、UIA访问和使用设置后的20秒稳态，以及系统记录的生命周期峰值。重复采样和交互测试详见 [3.0.1 内存优化记录](https://github.com/gura8390/ClickRun.Modern/blob/v3.0.1/rust/docs/verification-3.0.1.md)。测量不主动修剪工作集。

3.0.2 将图标六种尺寸无损改为原生 DIB 编码，保留全部像素和透明度，避免长期加载图标编解码模块。完整界面暖机后的平衡复测中，私有提交平均减少约 138 KiB；工作集差异存在波动。字体保留。详见 [3.0.2 暖态内存与归因记录](docs/verification-3.0.2.md)。

## 构建和测试

源码目录：`D:\codex\01-桌面工具\LmDmQi`。Rust 1.95、MSVC x64；`tools/build.ps1` 支持复用本机已有 SDK，也可通过参数指定 SDK 路径。`build.rs` 直接生成原生图标、中文版本和 DPI 清单资源，无需额外资源编译器。

```powershell
.\tools\build.ps1 -Action all
```

最终包包含可执行文件、微软运行库 `vcruntime140.dll` 和 `assets\FZGWKaiS.ttf`，无需安装 .NET Desktop Runtime。字体缺失时由系统字体回退，完整包仍应保留字体文件。旧 WPF 源码在原目录保留，Rust 重写源码与旧源码明确分开。

隔离测试必须使用独立配置目录；测试模式模拟输入，不向桌面发送鼠标事件，并自动隔离启动项和日志：

```powershell
.\连点器` Modern.exe --config-dir D:\测试目录 --test-mode
```

运行测试使用隔离配置和模拟输入，不向桌面发送鼠标事件。内存测试工具位于 `tools/memory-bench/`，驻留页归因工具位于 `tools/memory-profile/`；原始测量与测试数据保存在本机 `verification/memory-optimization/`。

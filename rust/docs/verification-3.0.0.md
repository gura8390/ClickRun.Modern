## 可见空闲样本

两次均在主窗口可见、停止连点时，每秒采样一次，各取得 20 个有效样本。旧 WPF 为长期运行进程，Rust 为正式发布配置；两次采样并非同时进行。

| 指标 | 旧 WPF | Rust 3.0.0 |
| --- | ---: | ---: |
| 平均工作集 | 130.43 MiB | 23.84 MiB |
| 平均私有提交量 | 75.48 MiB | 3.35 MiB |
| 进程 CPU 时间增量 | 1.9375 秒 | 采样分辨率内未观察到增量 |

该样本中，工作集约降低 **81.7%**，私有提交量约降低 **95.6%**。测量未主动清空或修剪工作集。

- 工作集取 `WorkingSet64`，包含共享驻留页。
- 私有提交量取 `PrivateMemorySize64`，包含可能被换出的页。
- CPU 通过进程累计 CPU 时间与墙钟时间计算；零增量表示本轮采样未分辨出消耗。

## 独立核心样本

两种实现均使用 Release 构建，以模拟发送器运行固定单击、无随机负载；各预热后执行一轮约 10 秒采样，核心样本不加载界面。

| 目标间隔 | 实现 | 实际计数速率 | 单核 CPU | 工作集中位数 | 私有提交中位数 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1 毫秒 | 旧 .NET 核心 | 570.8 次/秒 | 1.875% | 24.08 MiB | 7.16 MiB |
| 1 毫秒 | Rust 核心 | 670.3 次/秒 | 0.937% | 6.77 MiB | 1.30 MiB |
| 100 毫秒 | 旧 .NET 核心 | 9.885 次/秒 | 采样内未分辨出增量 | 24.05 MiB | 7.17 MiB |
| 100 毫秒 | Rust 核心 | 9.992 次/秒 | 采样内未分辨出增量 | 6.18 MiB | 1.23 MiB |

1 毫秒样本每千次计数的 CPU 时间约为 32.85 毫秒和 13.99 毫秒。核心模拟负载、完整应用可见空闲样本是不同的测量范围，分别列示。

# 连点器 Modern 3.0.1 内存优化记录

2026-11-16，Windows 11 x64（26100），32 个逻辑处理器。对比已发布 Rust 3.0.0 与本次 3.0.1，采用相同配置和操作顺序的新进程。下表为两次独立运行的均值，每个稳态区间持续 20 秒。设置往返两轮分别按旧版→新版、新版→旧版顺序执行。

## 实测结果

| 场景与指标 | 3.0.0 | 3.0.1 | 变化 |
| --- | ---: | ---: | ---: |
| 托盘启动后稳态工作集 | 17.518 MiB | 11.246 MiB | 减少 35.80% |
| 托盘启动后稳态私有提交 | 2.531 MiB | 1.846 MiB | 减少 27.08% |
| 托盘启动至采样结束的峰值工作集 | 17.518 MiB | 11.246 MiB | 减少 35.80% |
| 托盘启动至采样结束的峰值私有提交 | 2.531 MiB | 1.865 MiB | 减少 26.31% |
| 打开设置再返回主窗后的稳态工作集 | 23.734 MiB | 23.707 MiB | 基本持平 |
| 打开设置再返回主窗后的稳态私有提交 | 3.404 MiB | 3.285 MiB | 减少约 122 KiB（3.50%） |
| 进程启动至设置往返采样结束的峰值工作集 | 23.734 MiB | 23.752 MiB | 基本持平 |
| 进程启动至设置往返采样结束的峰值私有提交 | 3.416 MiB | 3.324 MiB | 减少约 94 KiB（2.69%） |

上述托盘和设置往返稳态区间，两版本均未测出 CPU 时间增长。普通可见窗口及 UIA 首次访问后的部分样本存在波动，不将其小幅差异宣传为稳定收益。托盘启动的收益适用于首次打开窗口之前；首次打开后需要创建完整界面并加载所需系统组件。

工作集包含共享驻留页；私有提交包含进程私有的已提交内存，可能包含已换出页，两者不能相加。1 MiB = 1,048,576 字节。

## 保留的优化

1. `--tray` 启动先初始化配置、热键和托盘，首次显示主窗时再创建控件、字体和无障碍名称服务。隐藏时仍支持启动、停止、指定次数自然结束、统计保存和错误缓存；打开窗口后读回实际状态。
2. 登录启动的真实系统查询在进入设置页时执行。注册项已确认启用时直接返回；其他情况继续检查快捷方式并保留原有错误处理。
3. 快捷方式的三个长文本字段共用一个 64 KiB 缓冲，保留完整长度能力，字符缓冲临时峰值确定减少 128 KiB。
4. UIAutomationCore 采用 MSVC 透明延迟加载，首次需要时加载；中文名称、RangeValue、Value、Selection、Toggle、Invoke 等语义与动作保持可用。
5. 首次从托盘显示正在运行的会话时，焦点进入可操作的停止按钮。

## 验证

- 21 项单元及系统集成测试通过，Release 构建零错误。
- 隐藏裸窗先经 UIA 访问，仍保持隐藏且无子控件；定向测试热键触发模拟单击七次，自然停止并保存；旧模式和随机字段归零。首次标准入口唤回后，UIA 读回停止、本次七次、累计七次。
- 六轮完整 UIA 交互均通过，每轮覆盖无效参数、按键与数值绑定、七次模拟单击、方案保存读取删除、设置保存及热键冲突处理，共 48 个通过步骤。
- 六轮交互各轮结束后工作集在 22.77–23.06 MiB、私有提交在 3.56–3.93 MiB 范围波动，未见随轮次持续增长；随后 20 秒稳定在 22.902 MiB / 3.559 MiB，CPU 时间增量为 0。该会话系统记录的峰值为 24.438 MiB 工作集、4.117 MiB 私有提交。
- 3.0.0 也执行了同样六轮交互，全部通过，记录的峰值为 24.453 MiB / 4.121 MiB，交互后稳态为 22.925 MiB / 3.637 MiB。完整交互后的峰值差异很小，两边最终句柄、GDI 和 USER 对象计数相同，说明收益集中在首次显示之前。
- 重启后的设置与统计读回通过；滚动回归、数字框几何居中、原生文本读写与选择、托盘菜单语义和菜单退出通过。退出后系统不再找到对应托盘图标。
- 所有启停交互使用明确隔离的模拟输入模式。主窗、托盘和设置暖态测量使用生产执行文件，正常模式通过独立 APPDATA/LOCALAPPDATA 隔离配置，只读取真实登录启动状态。

## 测量与停止依据

启动及托盘阶段每约 100 毫秒读取一次 `GetProcessMemoryInfo`；峰值使用操作系统自进程创建起记录的 `PeakWorkingSetSize` / `PeakPagefileUsage`，因此不依赖采样是否恰好碰到瞬间峰值。设置往返及重复交互后的稳态复用每秒一次、持续 20 秒的原有测量脚本。退出时的激活和关闭动作安排在测量结束后。未修剪工作集、强制 GC 或改变进程优先级、亲和性。

逐项保存了 A（延后 Shell 查询）、B（增加 UIA 延迟加载）、C（增加托盘首次建界面）候选；最终版本再次独立编译、重复测量并完成功能回归。收益集中在托盘和启动阶段，充分使用界面后的工作集已经基本持平。

驻留页归因显示主要开销为系统映像，原测量会话中自有程序映像驻留仅约 0.31 MiB。继续压缩 16 KiB 统计环、64 KiB 运行线程栈或少量界面对象，收益较小；删除字体、控件或无障碍能力会改变产品行为。本轮在保留已验证收益后停止。未采用激进卸载 COM 组件；微软说明过短的卸载延迟会增加清理竞态和重载开销：[CoFreeUnusedLibrariesEx](https://learn.microsoft.com/en-us/windows/win32/api/combaseapi/nf-combaseapi-cofreeunusedlibrariesex)。
